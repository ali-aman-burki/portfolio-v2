# Ali Aman - Portfolio

Source code for my personal portfolio website, live at [ali-aman.ca](https://ali-aman.ca).

Built with [Astro](https://astro.build) and deployed to GitHub Pages.

This is the second version of the site. The original (plain HTML/CSS/JS) is at [ali-aman-burki/portfolio-website](https://github.com/ali-aman-burki/portfolio-website).

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # production build to ./dist
```
